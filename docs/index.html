A medical fork of torch-fidelity

Generative metrics, now for medical scans.

torch-fidelity-med keeps the precision and caching that made torch-fidelity a reference for GAN evaluation, and extends it to volumetric medical imaging — 3D feature extractors, NIfTI inputs, 2.5D evaluation, and MS-SSIM, in one drop-in package.

What's added

Built for volumes, not just images.

Everything upstream still works. The fork adds the pieces you need when your generative model produces MRI, CT, or other 3D scans.

3D

Med3DNet feature extractors

Pretrained 3D ResNets — depths 10, 18, 34, 50, 101, 152, 200 — drop in as feature extractors for FID, KID, PRC, ISC.

·nii

NIfTI input, no glue code

Point --input1 at a directory of .nii.gz files. Volumes are loaded with nibabel and routed automatically.

2.5

2.5D evaluation

Run along axial, sagittal, or coronal orientations — or pass --vol-mode 2_5d to compute all three and report each plus their mean.

≈

MS-SSIM

Multi-scale structural similarity between two sets of samples, exposed via --msssim for paired image-quality reporting.

µ,Σ

Precomputed FID stats

Skip extracting input2 entirely — load µ and Σ from an .npz file via --fid_statistics_file.

↻

Per-orientation caching

Features and FID statistics are cached separately per orientation, so repeated 2.5D runs reuse work instead of recomputing it.

Quickstart

From pip install to a metric.

Install the package, point it at two directories of .nii.gz files, and pick a Med3DNet checkpoint. 

# install
pip install -e .
# medical extras
pip install nibabel einops "monai-generative"
# 3D FID with Med3DNet-50
fidelity --gpu 0 --fid \
  --feature-extractor med3dnet-50 \
  --feature-extractor-weights-path /path/to/resnet_50.pth \
  --vol-mode 3d \
  --input1 ./real/ --input2 ./generated/
# 2.5D — runs all three orientations, reports each and their mean
fidelity --gpu 0 --fid \
  --feature-extractor inception-v3-compat \
  --vol-mode 2_5d -b 4 \
  --input1 ./real/ --input2 ./generated/

# →  2_5_frechet_inception_distance_axial:    14.8
# →  2_5_frechet_inception_distance_sagittal: 16.1
# →  2_5_frechet_inception_distance_coronal:  15.4
# →  2_5_frechet_inception_distance_mean:     15.4

Keys are namespaced with a 2_5_ prefix and a _mean suffix so they slot cleanly into wandb dashboards alongside the per-orientation values.

Supported metrics

The full set, on 2D and 3D inputs.

Every upstream metric works with both image directories and NIfTI volumes; the feature extractor is the only thing that changes.

ISC — Inception Score FID — Fréchet Inception Distance KID — Kernel Inception Distance PRC — Precision & Recall PPL — Perceptual Path Length MS-SSIM (added)

Feature extractors

Pick the right backbone for your modality. 2D extractors apply to slices in 2.5D mode; 3D extractors operate on whole volumes.

inception-v3-compat vgg16 clip-rn50 / clip-vit-* dinov2-vit-* med3dnet-10 med3dnet-18 med3dnet-34 med3dnet-50 med3dnet-101 med3dnet-152 med3dnet-200
